# MIT 8103 Advanced Database Systems
## Database Design and Implementation Portfolio

**Student:** Ibrahim Balogun  
**Case Study:** BrightBank  
**Course:** MIT 8103 – Advanced Database Systems

### 1. Introduction

This portfolio presents the application of advanced database concepts to BrightBank, a fictional banking organisation. The project demonstrates database design, SQL querying and optimisation, transaction management, NoSQL modelling, and distributed database architecture. The work was developed progressively and documented in GitHub.

### 2. Portfolio Summary

**Portfolio 1: Database Design and Normalisation**

Designed a relational database for BrightBank using Customers, Accounts, and Transactions tables. Defined primary and foreign keys, constraints, relationships, sample data, and SQL queries. The design also considered normalisation to reduce redundancy and improve data integrity.

**Portfolio 2: Query Optimisation and Performance**

Developed SQL queries for customer, account, and transaction information. Documented indexing examples, execution-plan considerations, and performance optimisation techniques to improve query efficiency.

**Portfolio 3: Transactions and Concurrency**

Demonstrated transaction control using COMMIT and ROLLBACK. Examined concurrency challenges and database controls that support transaction consistency and reliable processing.

**Portfolio 4: NoSQL Database Design**

Developed a document-based customer model and supporting examples. Considered the suitability of NoSQL databases for flexible data structures, scalability, and banking use cases.

**Portfolio 5: Distributed and Cloud Databases**

Documented a proposed distributed database and cloud architecture for BrightBank. Considered replication, sharding, availability, consistency, and deployment implications.

### 3. Learning Reflection

The project improved my understanding of how database concepts support reliable information management in banking. I gained practical exposure to relational database design, SQL, transaction management, NoSQL data modelling, and distributed database architecture.

The exercise also reinforced the importance of data integrity, consistency, availability, performance, and scalability when designing databases for financial services.
