# MIT 8103 – Advanced Database Systems

## Banking System Database Portfolio

This repository contains my individual Continuous Assessment portfolio for MIT 8103 Advanced Database Systems.

## Case Study

A fictional banking system used to demonstrate database design, query optimisation, transaction management, NoSQL databases, and distributed database concepts. All customer and transaction data used in this project will be fictional.

## Portfolio Contents

1. Portfolio 1 – Database Design and Modelling
2. Portfolio 2 – Query Processing and Optimisation
3. Portfolio 3 – Transactions and Concurrency
4. Portfolio 4 – NoSQL and Advanced Data Models
5. Portfolio 5 – Distributed and Cloud Databases

## Purpose

To demonstrate the practical application of advanced database concepts through a banking system case study.

This is an individual academic project. All implementations, results, and explanations will be reviewed and verified by me. AI assistance will be disclosed in accordance with the course requirements.
